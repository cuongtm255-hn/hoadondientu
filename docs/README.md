# docs — project context for humans and Claude Code

Index of where context lives. Keep files short; link rather than duplicate.

## Tài liệu chính

- [SRS](requirements/SRS.md)
- [Wireframe HTML tương tác](wireframes/index.html)
- [Danh mục wireframe PNG](wireframes/README.md)

| Folder | Put here |
|---|---|
| `requirements/` | PM requirements, feature specs, acceptance criteria (source: portal "Tra cứu" behaviour + period-selection extension) |
| `wireframes/` | Interactive HTML wireframes and PNG exports, keyed by `SCR-xx` screen IDs |
| `architecture/` | Layering, module boundaries, auth/token-capture flow, diagrams |
| `decisions/` | ADRs, one file per decision (`NNNN-title.md`), e.g. WebView library choice |
| `api-samples/` | Captured portal API requests/responses (strip tokens and personal/tax data) |
| `plans/` | Implementation plans for in-flight work |
| `progress/` | Status log / handoff notes between sessions (what's done, next, blockers) |
| `runbooks/` | Build, release, and troubleshooting procedures |
